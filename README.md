# POLY schedule API

HTTP API расписания Московского Политеха. Берёт расписание группы с сайта
[rasp.dmami.ru](https://rasp.dmami.ru) и отдаёт дедлайны: лабораторные работы и практики.


## Как определяется дедлайн

Дедлайн — это пара, у которой в скобках в названии предмета написан тип работы:

| Название на сайте | Предмет | Тип работы |
|---|---|---|
| `Физика (лабораторная работа)` | Физика | лабораторная работа |
| `Программирование (практика)` | Программирование | практика |
| `Математика` | — | не дедлайн |

Узнаются и сокращения: «лаб. раб», «л/р», «практическое занятие», «пр. зан».
Если сайт заполняет у пары поле типа, оно тоже учитывается.

Это даты занятий, а не подтверждённые сроки сдачи заданий.
При очистке названия удаляются только скобки с типом работы; уточнения вроде
«Иностранный язык (английский)» сохраняются.

## Запуск

Нужен Python 3.10 или новее.

```bash
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8000
```

Или просто запустите `python main.py`: сервер поднимется на порту 8000.

Интерактивная документация открывается по адресу `http://<сервер>:8000/docs`.

## Дедлайны за день или период

```
GET /deadlines/{группа}?date=ДД.ММ.ГГГГ
GET /deadlines/{группа}?from=ДД.ММ.ГГГГ&to=ДД.ММ.ГГГГ
```

| Параметр | Обязательный | Описание |
|---|---|---|
| `группа` | да | номер группы, например `231-321` |
| `date` | да, если нет `from` и `to` | один день |
| `from`, `to` | да, если нет `date` | начало и конец периода, оба дня включаются |
| `format` | нет | `json` (по умолчанию) или `text` |
| `session` | нет | `true` — брать расписание сессии вместо семестра |

Даты принимаются только в формате **ДД.ММ.ГГГГ** (`03.11.2026`). Период не длиннее 366 дней.

### Ответ в JSON

Массив записей, отсортированных по дате и номеру пары. Пустой массив означает, что дедлайнов нет.

```bash
curl "http://localhost:8000/deadlines/231-321?from=01.11.2026&to=14.11.2026"
```

```json
[
  {"date": "02.11.2026", "subject": "Физика", "type": "лабораторная работа"},
  {"date": "04.11.2026", "subject": "Программирование", "type": "практика"}
]
```

| Поле | Описание |
|---|---|
| `date` | дата пары, ДД.ММ.ГГГГ |
| `subject` | название предмета без скобок с типом работы |
| `type` | `лабораторная работа` или `практика` |

### Ответ текстом

С `format=text` каждая запись — строка `дата;предмет;тип работы`. Так проще разбирать ответ на ESP32.

```bash
curl "http://localhost:8000/deadlines/231-321?date=02.11.2026&format=text"
```

```
02.11.2026;Физика;лабораторная работа
```

Если дедлайнов нет, тело ответа пустое.

## Другие запросы

| Запрос | Что возвращает |
|---|---|
| `GET /deadlines/{группа}/next` | ближайший дедлайн на 60 дней вперёд и поле `say` с готовой фразой для озвучки |
| `GET /schedule/{группа}/day?day=ГГГГ-ММ-ДД` | все пары на день, по умолчанию на сегодня |
| `GET /schedule/{группа}` | всё расписание группы в разобранном виде |

Пример `say`: «Лабораторная работа по предмету Физика завтра, в 09:00, аудитория Пр2302.»

## Ошибки

Ошибка приходит в JSON вида `{"detail": "текст ошибки"}`.

| Код | Когда |
|---|---|
| 400 | неверный формат даты, не указан период, `to` раньше `from` или период слишком длинный |
| 404 | группа не найдена на сайте |
| 502 | rasp.dmami.ru недоступен или вернул некорректные данные |

Ответы сайта кэшируются на 10 минут, поэтому изменения в расписании видны с такой задержкой.
Кэш ограничен 128 записями (группа + признак сессии). Просроченные записи
удаляются при следующем обращении; при заполнении вытесняется самая старая запись.

Пустой день (`null`, `{}` или `[]`) означает отсутствие занятий. Некорректная
дата, структура или тип поля в непустом расписании возвращают ошибку 502,
а не частичный результат. HTML-заглушка источника также считается ошибкой 502;
404 используется для сообщения источника о ненайденной группе.

## Проверка

Автоматические тесты (без обращения к настоящему сайту):

```bash
python -m pytest -q
```

Проверка работающего сервера выполняется отдельно:

```bash
python -m uvicorn main:app --host 127.0.0.1 --port 8000
```

Откройте `http://127.0.0.1:8000/docs` или выполните в другом терминале:

```bash
curl "http://127.0.0.1:8000/deadlines/231-321?from=02.11.2026&to=08.11.2026"
```

Автоматизированная проверка работающего сервера (13 HTTP-запросов):

```bash
python scripts/check_live_api.py --output live_api_results.json
```

Скрипт проверяет группы `231-321` и `261-329` за 2-8 ноября 2026 года.
Параметры `--group`, `--other-group` и `--base-url` можно изменить.
После запуска полные ответы сервера сохраняются в `live_api_results.json`.
JSON сохраняется также при ошибке соединения, HTTP-статуса или содержимого ответа.
Путь можно задать самостоятельно:

```bash
python scripts/check_live_api.py --output reports/results.json
```

Результат реального запроса зависит от актуального расписания и доступности сайта.
